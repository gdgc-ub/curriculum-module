# Introduction
Before entering the learning, there are several extensions that should be installed to make it easier to follow the material about HTML and so on. One important extension is the live server

![Live Server](../../../../public/assets/web-development/liveserver.png)

This extension is useful for displaying the results of html, css and js tags that you write how to use it click the go live button at the bottom left of your vs code display

![Go live](../../../../public/assets/web-development/golive.png)

if you turn on live it will move your display to the local web host to display the html and css code that you wrote like this: 
![Go live](../../../../public/assets/web-development/startlive.jpeg)

but different to display the results of the java script file what you have to do is right-click on the screen, then select inspect, and select console there will output from the js language that you want to display.

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>
    <h1>This is example page </h1>
</body>
</html>
```
