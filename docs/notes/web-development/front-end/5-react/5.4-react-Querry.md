# React Querry
> Learn how to declare query keys, define query functions, and work with different data fetching states in React Query.

library for data fetching and asynchronous state management in React applications so that by using React Query we as users can easily retrieve, store, and update data from APIs or other data sources. so it can be said that react query makes it easier to manage states related to asynchronous data, such as loading, errors, and caching.

To run React Query, you must install React Query with this command on your terminal:
```
npm install @tanstack/react-query
```

In React Query, the main features that help simplify your code are:

### 1. `Query` Used to fetch data from an API efficiently. It manages loading, error, and success states automatically.

Example: 
```jsx
import { useQuery } from '@tanstack/react-query';
import axios from 'axios';

function FetchPosts() {
  const { data, isLoading, error } = useQuery({
    queryKey: ['posts'],
    queryFn: async () => {
      const res = await axios.get('{https://}');
      return res.data;
    },
  });

  if (isLoading) return <p>Loading...</p>;
  if (error) return <p>Error: {error.message}</p>;

  return (
    <ul>
      {data.map(post => (
        <li key={post.id}>{post.title}</li>
      ))}
    </ul>
  );
}
```


### 2. `Mutation` Helps you modify data on the server, such as `POST`, `PUT`, or `DELETE`, while keeping your UI in sync.

Example:
```jsx
import { useMutation, useQueryClient } from '@tanstack/react-query';
import axios from 'axios';

function AddPost() {
  const queryClient = useQueryClient();

  const mutation = useMutation({
    mutationFn: async (newPost) => {
      return await axios.post('https://', newPost);
    },
    onSuccess: () => {
      queryClient.invalidateQueries(['posts']); // Refresh query 'posts'
    },
  });

  const handleAddPost = () => {
    mutation.mutate({ title: 'New Post', body: 'This is a new post.' });
  };

  return (
    <button onClick={handleAddPost} disabled={mutation.isLoading}>
      {mutation.isLoading ? 'Saving...' : 'Add Post'}
    </button>
  );
}
```

### 3. `Query Invalidation` Automatically refreshes cached data when changes occur, ensuring users always see the latest information.

Example: 
```jsx
import { useQueryClient } from '@tanstack/react-query';

function RefreshPosts() {
  const queryClient = useQueryClient();

  const handleRefresh = () => {
    queryClient.invalidateQueries(['posts']); // Refresh data with key 'posts'
  };

  return <button onClick={handleRefresh}>Refresh Posts</button>;
}
```

### 4. `Polling and Refetching` Allows you to periodically refresh data to keep it up-to-date without user interaction.

Example:
```jsx 
import { useQuery } from '@tanstack/react-query';
import axios from 'axios';

function PollingPosts() {
  const { data, isLoading, error } = useQuery({
    queryKey: ['posts'],
    queryFn: async () => {
      const res = await axios.get('https://jsonplaceholder.typicode.com/posts');
      return res.data;
    },
    refetchInterval: 5000, // Refetch every 5 seconds
  });

  if (isLoading) return <p>Loading...</p>;
  if (error) return <p>Error: {error.message}</p>;

  return (
    <ul>
      {data.map(post => (
        <li key={post.id}>{post.title}</li>
      ))}
    </ul>
  );
}
```

### 5. `Devtools` Provides a visual debugging interface to monitor query states, cache data, and errors in real-time.

Example:
```jsx
import { QueryClient, QueryClientProvider } from '@tanstack/react-query';
import { ReactQueryDevtools } from '@tanstack/react-query-devtools';

const queryClient = new QueryClient();

function App() {
  return (
    <QueryClientProvider client={queryClient}>
      <YourComponent />
      <ReactQueryDevtools initialIsOpen={false} />
    </QueryClientProvider>
  );
}
```
In the devtools component, to run ReactQueryDevtools into the QueryClientProvider, you must install it with:
```
npm install @tanstack/react-query-devtools
```

To better understand the implementation, here is a complete example of the implementation of the five main components to create a Task List management website that has the following features:

1. Display task data from API with automatic refresh.

2. Add new tasks to the server and update the task list automatically.

```jsx
import React from 'react';
import { QueryClient, QueryClientProvider, useQuery, useMutation, useQueryClient } from '@tanstack/react-query';
import { ReactQueryDevtools } from '@tanstack/react-query-devtools';
import axios from 'axios';

// Setup Query Client
const queryClient = new QueryClient();

// API Endpoints
const fetchProducts = async () => {
  const { data } = await axios.get('https://fakestoreapi.com/products');
  return data;
};

const addProduct = async (newProduct) => {
  const { data } = await axios.post('https://fakestoreapi.com/products', newProduct);
  return data;
};

// 1. Component to Display Products (Query)
function ProductList() {
  const { data: products, isLoading, error, refetch } = useQuery({
    queryKey: ['products'],
    queryFn: fetchProducts,
    refetchInterval: 15000, // Polling every 15 seconds
  });

  if (isLoading) return <p>Loading products...</p>;
  if (error) return <p>Error loading products: {error.message}</p>;

  return (
    <div>
      <h3>Product List</h3>
      <ul>
        {products.map(product => (
          <li key={product.id}>
            {product.title} - ${product.price}
          </li>
        ))}
      </ul>
      <button onClick={refetch}>Refresh Products</button>
    </div>
  );
}

// 2. Component to Add a New Product (Mutation + Query Invalidation)
function AddProduct() {
  const queryClient = useQueryClient();

  const mutation = useMutation({
    mutationFn: addProduct,
    onSuccess: () => {
      queryClient.invalidateQueries(['products']); // Refresh product data
    },
  });

  const handleAddProduct = () => {
    const newProduct = {
      title: `Product ${Date.now()}`,
      price: Math.floor(Math.random() * 100) + 1,
      description: 'A new product description',
      category: 'electronics',
      image: 'https://via.placeholder.com/150',
    };
    mutation.mutate(newProduct);
  };

  return (
    <div>
      <button onClick={handleAddProduct} disabled={mutation.isLoading}>
        {mutation.isLoading ? 'Adding Product...' : 'Add New Product'}
      </button>
    </div>
  );
}

// Main App Component
function App() {
  return (
    <QueryClientProvider client={queryClient}>
      <div style={{ padding: '20px' }}>
        <h1>Fake Store Manager</h1>
        <ProductList />
        <AddProduct />
      </div>
      <ReactQueryDevtools initialIsOpen={false} />
    </QueryClientProvider>
  );
}

export default App;
```
