## 1. useState
useState is a hook in React that is used to add state to a function component. With useState, a function component can store and update values ​​that change throughout the component's lifecycle.

When you call useState, you get two things:

The current state (The value you saved) and a function to update the state (Used to change the value of the state).

Example 
```jsx
const [state, setState] = useState(initialValue);
```

`initialValue` in this example is the initial value of the state.

Examples in implementation to create increment and decrement:
```jsx
import React, { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0); // State starts from 0

  return (
    <div>
      <h1>Count: {count}</h1>
      <button onClick={() => setCount(count + 1)}>Increment</button>
      <button onClick={() => setCount(count - 1)}>Decrement</button>
    </div>
  );
}

export default Counter;
```


## 2. useEffect
hooks in React that allow you to handle side effects in function components. Side effects include things like:
Fetching data from an API, Updating the document title, and Handling event listeners or timers.

The useEffect function is executed every time the component is rendered. You can also control when the effect is executed by adding dependencies.

Example:
```jsx
useEffect(() => {
  // Effects that are executed
  return () => {
    // (Optional) Clear previous effects
  };
}, [dependencies]);
```
in the example above The Effect Function is the `first function` in useEffect where you write the side effects. then there is the
`Cleanup Function` which is used to clean up the previous effect (for example, deleting an event listener). the last is the `Dependency Array` which is used to determine when the effect is run.


In use effect we can choose when the effect we give is rendered, whether when the component is first rendered, every time the state or props change, or we want to clean up the effect.

Example Running Effect Every Time State or Props Change: 
```jsx
import React, { useState, useEffect } from "react";

function LocalData() {
  const [data, setData] = useState([]);
  const [count, setCount] = useState(0);

  useEffect(() => {
    // Local data that simulates fetching from an API
    const localData = [
      { id: 1, title: "First Item" },
      { id: 2, title: "Second Item" },
      { id: 3, title: "Third Item" },
      { id: 4, title: "Fourth Item" },
      { id: 5, title: "Fifth Item" },
    ];

    // Updating state with local data
    setData(localData);
  }, [count]); // Effect reruns when 'count' changes

  return (
    <div>
      <button onClick={() => setCount(count + 1)}>Refresh Data</button>
      <ul>
        {data.map((item) => (
          <li key={item.id}>{item.title}</li>
        ))}
      </ul>
    </div>
  );
}

export default LocalData;
```

There are 3 ways to use dependencies such as:

dependency Without Array: Effect is executed every time the component is rendered
```jsx 
useEffect(() => {
  console.log("Effects are always running");
});
```

dependencies With Empty Array: The effect is only executed once (when the component is first rendered).
```jsx
useEffect(() => {
  console.log("Effect is executed once");
}, []);
```

dependencies With Dependency Variables: The effect is re-executed when any of the variables in the dependency array changes.
```jsx
useEffect(() => {
  console.log("Effect reruns because 'count' changes");
}, [count]);
```

## 3. useContext
hook in React that is used to access data from a context without having to pass the data through props from one component to another. With useContext, you can directly retrieve values ​
​from the context created with React.createContext. useContext is very useful when you have data that you want to use by many components in an application such as the application theme 
(dark/light mode), logged-in user data and many others.


How useContext Works: 
1. Create Context with `React.createContext`
```jsx
const MyContext = React.createContext(defaultValue);
```

2. Use `Context Provider` to Provide Values. `Provider` is used to define data that can be accessed by other components.
```jsx
<MyContext.Provider value={someValue}>
  {children}
</MyContext.Provider>
```

3. Use `useContext` to Get Values. Child components can access values ​​from context without props drilling.
```jsx
const value = useContext(MyContext);
```


Example its use in Application Theme (Dark/Light Mode):
```jsx
import React, { useContext, useState } from "react";

// Buat context
const ThemeContext = React.createContext();

function ThemeProvider({ children }) {
  const [theme, setTheme] = useState("light");

  const toggleTheme = () => {
    setTheme((prevTheme) => (prevTheme === "light" ? "dark" : "light"));
  };

  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  );
}

function ThemedButton() {
  const { theme, toggleTheme } = useContext(ThemeContext); // Get context value

  return (
    <button
      onClick={toggleTheme}
      style={{
        backgroundColor: theme === "light" ? "#fff" : "#333",
        color: theme === "light" ? "#000" : "#fff",
      }}
    >
      Toggle Theme
    </button>
  );
}

function App() {
  return (
    <ThemeProvider>
      <ThemedButton />
    </ThemeProvider>
  );
}

export default App;
```
from the example above for ThemeContext as a context used to store theme data, then for ThemeProvider to supply theme data and toggleTheme function,
and finally the ThemedButton to access theme data directly using useContext.

## 4. useRef
useRef is a hook in React that is used to create references to DOM elements or store values ​
​that do not trigger a re-render when changed. This hook is very useful for accessing DOM elements directly, and storing values 
​​that you want to remain consistent throughout the component's lifecycle without triggering a re-render.

How useRef Works:

1.When using useRef, this hook returns an object that has a current property. The current property can be used to store or read values 
​​so that changes to ref.current will not cause the component to re-render.
```jsx
const ref = useRef(initialValue);
```

Example of using useref to Save Previous Value:
```jsx
import React, { useState, useRef, useEffect } from "react";

function PreviousValue() {
  const [value, setValue] = useState("");
  const prevValueRef = useRef("");

  useEffect(() => {
    prevValueRef.current = value; // Save current value to ref
  }, [value]); // Only executed when 'value' changes

  return (
    <div>
      <input
        type="text"
        value={value}
        onChange={(e) => setValue(e.target.value)}
      />
      <p>Current Value: {value}</p>
      <p>Previous Value: {prevValueRef.current}</p>
    </div>
  );
}

export default PreviousValue;
```
It can be concluded that the use of useRef With useRef you can handle DOM elements and store values ​​
in an efficient way without affecting the React rendering cycle.

## 5. useReducer
hooks in React are used to manage complex states. This is an alternative to useState when we create a web and have states 
that depend on many conditions or logic, then we want to separate the state update logic from the component.

How useReducer Works:

1.Reducer Function (A function that determines how the state is updated based on actions)
```jsx
const reducer = (state, action) => {
  switch (action.type) {
    case "increment":
      return { count: state.count + 1 };
    case "decrement":
      return { count: state.count - 1 };
    default:
      return state;
  }
};
```

2. Initial State(Initial state value)
```jsx
const initialState = { count: 0 };
```

3. useReducer returns an array with two elements, 
the first is state (Current state value) and the second is dispatch (Function to send action to reducer)
```jsx
const [state, dispatch] = useReducer(reducer, initialState);
```

Example of using useReducer to make a simple calculation: 
```jsx
import React, { useReducer } from "react";

const initialState = { count: 0 };

function reducer(state, action) {
  switch (action.type) {
    case "increment":
      return { count: state.count + 1 };
    case "decrement":
      return { count: state.count - 1 };
    case "reset":
      return initialState;
    default:
      throw new Error("Unknown action");
  }
}

function Counter() {
  const [state, dispatch] = useReducer(reducer, initialState);

  return (
    <div>
      <h1>Count: {state.count}</h1>
      <button onClick={() => dispatch({ type: "increment" })}>Increment</button>
      <button onClick={() => dispatch({ type: "decrement" })}>Decrement</button>
      <button onClick={() => dispatch({ type: "reset" })}>Reset</button>
    </div>
  );
}

export default Counter;
```
`dispatch` in this example is used to send actions to the reducer.

so it can be concluded that the use of useReducer is to make it easier for us to
manage state in a more structured way and separate logic clearly, especially for complex cases.

## 6. Custom Hooks
Custom hooks are JavaScript functions that start with the word "use" and allow you to extract reusable logic from React components. 
So it can be said that if we use custom hooks we can group related logic without having to duplicate code across components. These custom 
hooks take advantage of built-in hooks like the other "use" ones we've learned above to create more modular and manageable logic.

How to Create a Custom Hook
1. The name of the custom hook must start with the word `use` so that React recognizes that it is a hook.

2. Second, use built-in hooks (`useState`, `useEffect`, and others) to create logic inside the custom hook.

3. Return a value (`data`, `function`, or `object`) that will be used by the component.

example of using custom hooks to Manage Forms: 

create a file named useForm to manage the form state and provide a handleChange function to update the state.
```jsx
import { useState } from "react";

function useForm(initialValues) {
  const [values, setValues] = useState(initialValues);

  const handleChange = (e) => {
    const { name, value } = e.target;
    setValues({
      ...values,
      [name]: value,
    });
  };

  const resetForm = () => {
    setValues(initialValues);
  };

  return { values, handleChange, resetForm };
}

export default useForm;
```

call pre-made custom hooks to manage form data without having to rewrite logic.
```jsx
import React from "react";
import useForm from "./useForm";

function FormExample() {
  const { values, handleChange, resetForm } = useForm({ name: "", email: "" });

  const handleSubmit = (e) => {
    e.preventDefault();
    console.log(values);
    resetForm();
  };

  return (
    <form onSubmit={handleSubmit}>
      <input
        type="text"
        name="name"
        value={values.name}
        onChange={handleChange}
        placeholder="Name"
      />
      <input
        type="email"
        name="email"
        value={values.email}
        onChange={handleChange}
        placeholder="Email"
      />
      <button type="submit">Submit</button>
    </form>
  );
}

export default FormExample;
```

So if we have constraints such as Complex State Management, Overly Complicated Components, and Reused Logic, it would be very good to use 
custom hooks to make React applications more modular, neat, and easy to manage.
