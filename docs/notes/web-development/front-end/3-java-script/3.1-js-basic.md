## 1. Variabel
Variables are used to store data. There are three ways to declare variables: var, let, and const.

Each variable has characteristics so that it has its own function such as:

### 1.1 `const` is used for values ​​that will not change (default choice).
```js
const d = 30;
console.log(d);
```

### 1.2 `let` is used if the value needs to be changed.
```js
let name = "John"; 
console.log(name); 
```

### 1.3 `var` it is rarely used because it can easily cause bugs (due to hoisting and scope).
```js
var x = 10;
console.log(x);
```

## 2. Tipe Data

### 2.1 String
String is a text or a collection of characters written in quotation marks. Strings are used to store text such as names, sentences, or symbols.
```js
let name = "Nickolas"; 
```

### 2.2 Number
Number is a data type for numbers, both integers and floating-point numbers. So it can be said that writing numbers in JavaScript is different from Java because the entire number only requires a number variable. There are no separate types such as int, double, or float.
```js
let score = 95.5; 
```

```js
let score = 20; 
```


### 2.3 Boolean
Boolean is a data type that only has two values `true` and `false`. Boolean is used to express logical conditions, such as the results of comparisons or logical tests in a program.
```js
let isStudent = true;
// or 
let isStudent = false;
```

### 2.4 Array
Array is a data structure in JavaScript that is used to store multiple values ​​in one variable. Arrays can contain various data types such as numbers, strings, booleans, objects.
```js
let fruits = ["Apple", "Banana", "Cherry"];
```

### 2.5 Object
Objects in JavaScript are data types that allow you to store collections of data consisting of key and value pairs. Keys can be strings or symbols, while values ​​can be any type of data, including strings, numbers, arrays, or even other objects. Objects are often used to describe real-world entities, such as cars, people, or products, that have various properties and methods (functions). 
```js
let person = { name: "Alice", age: 30 };
```


## 3. if-else 
it is a a control structure used to make decisions in a program. By using if-else, you can direct a program to execute certain code based on given conditions. 

The basic structure of if-else consists of:

`if`: Evaluates the condition and executes code if the condition is true.

`else`: Executes alternative code if the if condition is not met (false).
```js
let score = 85;

if (score >= 90) {
  console.log("Grade: A");
} else if (score >= 75) {
  console.log("Grade: B");
} else {
  console.log("Grade: C");
}
```

## 4. Loops 
`For` Loop are used when you know how many times you want to repeat the loop. They are usually used when there is an index or counter that can be counted.

The syntax of the for loop consists of:

`Initialization`: Setting the initial variable to count iterations (usually used for indexes).

`Condition`: The condition that is checked before each iteration. As long as this condition is true, the loop will continue.

`Increment`: Changing the variable after each iteration (usually used to count backward or forward).
```js 
for (initialization; condition; increment) {
}

```

Example how to use For loop: 
```js
for (let i = 1; i <= 5; i++) {
  console.log("Angka:", i);
}
```
---

`While` Loop used when you don't know in advance how many times the loop will run, and just want to keep repeating as long as a condition is true.

The syntax of the for loop consists of:

`Condition`: The condition that will be evaluated before each iteration. As long as this condition is true, the loop will continue.

```js
while (condition) {

}

```

Example how to use While loop: 
```js
let count = 1;
while (count <= 3) {
  console.log("Hitungan:", count);
  count++;
} 
```

## 5. Functions
Function is a code that can be called to perform a specific task. Functions allow you to group frequently used code into one place, so that it can be called back at any time without having to rewrite the same code.

For Example: 
```js 
function greet(name) {
  return "Hello, " + name;
}

console.log(greet("Nickolas"));
```
In the code above, we don't need to type hello, we just call the greet function and enter the name we want to greet.
