# React Router 
> Learn how to declare routes, define navigation logic, and work with different URL paths in React Router.

library used in React to create navigation between pages in web applications. 
React Router allows you to create Single Page Applications (SPAs) with navigation experiences like multi-page applications.

The main components that we can use to run React Router are:

1. BrowserRouter (The main component that wraps your application to enable routing.) 
```jsx
import { BrowserRouter } from "react-router-dom";

const App = () => {
  return (
    <BrowserRouter> {/*this is a router browser*/}
      <div>My App with React Router</div>
    </BrowserRouter>
  );
};

export default App;
```

2. Routes (A place to define all your application routes) 
```jsx
import { BrowserRouter, Routes, Route } from "react-router-dom";

const Home = () => <h1>Home</h1>;
const About = () => <h1>About</h1>;

const App = () => {
  return (
    <BrowserRouter>
      <Routes> {/* These are the routes */}

      </Routes>
    </BrowserRouter>
  );
};

export default App;
```

3. Route (Defines each individual route. Routes have path properties for the URL and element properties for the component to display)
```jsx
import { BrowserRouter, Routes, Route } from "react-router-dom";

const Home = () => <h1>Home</h1>;
const About = () => <h1>About</h1>;

const App = () => {
  return (
    <BrowserRouter>
    <Routes> {/* These are the routes */}
        <Route path="/" element={<h1>Home</h1>} />
        <Route path="/about" element={<h1>About</h1>} />
        <Route path="/contact" element={<h1>Contact</h1>} />
    </Routes>
    </BrowserRouter>
  );
};

export default App;
```

4. Link (Used to navigate between pages without reloading. Similar to <a> in HTML but specific to React Router)

```jsx
import { BrowserRouter, Routes, Route, Link } from "react-router-dom";

const Home = () => <h1>Home</h1>;
const About = () => <h1>About</h1>;

const App = () => {
  return (
    <BrowserRouter>
      <nav>
        <Link to="/">Home</Link>
        <Link to="/about">About</Link>  {/* These are the Link */}
      </nav>
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />
      </Routes>
    </BrowserRouter>
  );
};

export default App;
```

5. useNavigate ( is a Hook for programmatic navigation)
```jsx
import { BrowserRouter, Routes, Route, useNavigate } from "react-router-dom";

const Home = () => {
  const navigate = useNavigate();

  const goToAbout = () => {
    navigate("/about"); {/* Navigate to the "/about" page  */}
  };

  return (
    <div>
      <h1>Home</h1>
      <button onClick={goToAbout}>To About Page</button>
    </div>
  );
};

const About = () => <h1>About</h1>;

const App = () => {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />
      </Routes>
    </BrowserRouter>
  );
};

export default App;
```

You can use the first three components (BrowserRouter, Routes, and Route) together to set up routing for your React app. The fourth component (Link) is used for navigation between pages without reloading, and it works together with the first three components.

However, the fifth (useNavigate) is different because it’s a hook. It allows you to navigate between pages using JavaScript logic instead of clickable links. You can choose to use either Link or useNavigate, depending on whether you want users to click a link or navigate programmatical

```jsx
import React from "react";
import { BrowserRouter, Routes, Route, Link } from "react-router-dom";

const Home = () => <h1>Beranda</h1>;
const About = () => <h1>Tentang</h1>;
const Contact = () => <h1>Kontak</h1>;

const App = () => {
  return (
    <BrowserRouter>
      <nav>
        <Link to="/">Beranda</Link>
        <Link to="/about">Tentang</Link>
        <Link to="/contact">Kontak</Link>
      </nav>
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />
        <Route path="/contact" element={<Contact />} />
      </Routes>
    </BrowserRouter>
  );
};

export default App;
```
