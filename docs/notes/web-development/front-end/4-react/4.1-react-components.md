# React Components 
> Learn how to declare variables, define functions, and work with different data types.

React Components are like small, reusable pieces of code that work together to build a user interface (UI). Think of them as the building blocks of a React application, similar to LEGO pieces that combine to create something bigger. Components can represent parts of a website, such as a Navbar, Footer, Button, or Card, and they help make your code more organized and easier to manage. Among the types of components, Functional Components are simple and powerful, offering key features like `reusability` (the ability to use the same component in different parts of the app), `props` (passing data to components), `state` (managing dynamic data within the component), and `composition` (combining components to build more complex UIs). These features make Functional Components an essential tool for building flexible and interactive web applications.

::: details Overview of the Materials 📚

- **Functional Components:** Simple functions that return JSX, used for building UI in React.
- **Props (Properties):** Mechanism to pass data from a parent component to a child component.
- **State:** A way to store and manage dynamic data that can change over time in a component.
- **Lists and Keys:** Used to efficiently render and track items in an array by assigning unique keys to each element.
- **Handling Events:** The process of responding to user actions like clicks, inputs, or key presses within React components.

::: 

## 1. Functional Components
This component is a plain JavaScript function that accepts props as parameters and returns a React element (usually JSX).Functional components are often used because they are easier to understand, maintain, and work better with modern features like React Hooks.

###  1.1 Reusability 
It can be used repeatedly in various places within the application.

Example:

So in this example I created 2 files where 1 file is for displaying and the other is for functional components. In this example I created button components.

File for Button Components: 
```jsx
import React from "react";

function Button(props) {
  return (
    <button style={{ padding: "10px 20px", fontSize: "16px" }}>
      {props.label}
    </button>
  );
```


### 1.2 Props (Properties)
Props stands for "properties," which are used to send data from one component to another in React. Props are read-only so that data sent via props cannot be changed by the receiving component.


Example:

File for Greeting props: 
```jsx
import React from "react";

function Greeting(props) {
  return <h1>Hello, {props.name}!</h1>;
}

export default Greeting;
```

File for Displayed :

```jsx
import React from "react";
```

### 1.3. State
one of the main features in React that is used to store and manage data that changes during the lifecycle of a component. Unlike props, which are read-only, state is mutable. with the state of your web you can want to store data that can change (for example, form input values, login status, or items in the shopping cart). not only that, components that require data that is updated based on user interaction must also use state to store updates. so that the web you create can be very interactive with its users.

Example:
```jsx
import React, { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  const increment = () => setCount(count + 1);

  const decrement = () => setCount(count - 1);

  return (
    <div style={{ textAlign: "center", marginTop: "50px" }}>
      <h1>Counter: {count}</h1>
      <button onClick={increment} style={{ marginRight: "10px" }}>
        +
      </button>
      <button onClick={decrement}>-</button>
    </div>
  );
}

export default Counter;
```


## 2. Lists and Keys
an important concept in React that is used to display a collection of data efficiently in the form of a list. Usually a list is created by mapping array data to React elements. Well, in this concept there are lists and keys that have different functions such as

`Lists` are used to render elements that come from arrays or other data sets. while `Keys` are special attributes that help React identify which elements have changed, been added, or removed when the list is updated.

Lists Example:
```jsx
import React from "react";

function NameList() {
  const names = ["Alice", "Bob", "Charlie"];

  return (
    <ul>
      {names.map((name) => (
        <li >{name}</li>
      ))}
    </ul>
  );
}

export default NameList;
```

for `keys` is quite important because keys can be used to determine which elements in the list need to be updated, added, or removed. Without a unique key, React might re-render the entire list, which is inefficient.
like this example:
```jsx 
import React from "react";

function TodoList() {
  const todos = [
    { id: 1, task: "Learn React" },
    { id: 2, task: "Build a project" },
    { id: 3, task: "Master React" },
  ];

  return (
    <ul>
      {todos.map((todo) => (
        <li key={todo.id}>{todo.task}</li> {/* Key by id */}
      ))}
    </ul>
  );
}

export default TodoList;
```

If your data array doesn't have an id to use as a `key` like in the first list example, you can create a `key `using the index of each item in the array, like this:

```jsx
import React from "react";

function NameList() {
  const names = ["Alice", "Bob", "Charlie"];

  return (
    <ul>
      {names.map((name, index) => (
        <li key={index}>{name}</li> 
      ))}
    </ul>
  );
}

export default NameList;
```

Just a suggestion for Best Practices in creating lists Always use unique keys, especially if the list is dynamic or the data in it may change.

## 3.  Handling Events
how to handle user actions, such as button clicks, typing on input, or other events that occur in the interface. 


Example: 
```jsx

function InputChange() {
  const [text, setText] = useState("");
```
