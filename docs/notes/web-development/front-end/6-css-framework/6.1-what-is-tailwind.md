# What is Tailwind CSS
> Learn About Tailwind Css like what different between tailwind and vanilla css and how to install tailwind css

Tailwind is a utility-first CSS framework, meaning you use the small classes provided by Tailwind to build designs directly in your HTML, without having to write CSS from scratch. This framework is different from Bootstrap, shaden, and other frameworks which provide ready-to-use components such as buttons or navbars so that we only need to copy and paste. In Tailwind, we as users have the fun of creating completely custom designs, without having to overwrite or change the default style.

Some of the advantages of using Tailwind are its high flexibility, because it allows detailed design adjustments without having to change the CSS file. This framework also strongly supports a mobile-first approach to responsiveness, using prefixes such as `sm:`, `md:`, `lg:`,and `xl` to design displays on various screen sizes. In addition, Tailwind CSS supports custom configuration through the tailwind.config.js file, which allows developers to add themes, colors, or utilities according to project needs.

Berikut adalah beberapa contoh perbandingan dari menggunakan tailwind dan hanya menggunakan vannila css (CSS Murni): 

Contoh styling button Menggunakan Vanilla CSS:
```html
<button class="button">Click Me</button>
```

```css
.button {
    background-color: blue;
    color: white;
    padding: 10px 20px;
    border-radius: 5px;
    text-align: center;
}
```

Menggunakan Tailwind CSS: 
```html
<button class="bg-blue-500 text-white px-4 py-2 rounded text-center">Click Me</button>
```

Contoh Styling background menggunakan Vanilla CSS:
